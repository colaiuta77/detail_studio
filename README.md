# Detail Studio

BookOrbit의 차분한 탭 구성을 참고한 BookOasis 도서 상세페이지 플러그인입니다.

| 항목 | 내용 |
| --- | --- |
| 버전 | 0.5.0 |
| 적용 대상 | 일반·성인 도서·오디오북·비디오북 |
| 기준 코어 | 코어 main `9ba7c93` (공식 다운로드·등급·rating_widget 계약 기준) |
| 필수 계약 | `detail_view`, `/api/media/plugins/{id}/detail-ui` |
| 외부 의존성 | 없음. BookOasis의 Flask·DB Gateway·Font Awesome을 사용합니다. |
| DB | SQLite 실제 쿼리 테스트 통과. MariaDB 정적 호환 검사 통과, 실서버 미검증. |

## 화면

- **개요.** 표지·소개·메타정보 요약·권별 평균 진행률·이어 읽기.
- **시리즈.** 카드/목록 전환, 제목 검색, 미독/읽는 중/완독 필터.
- **파일.** 경로 펼치기/복사, 확장자, 마지막 스캔 용량·수정일, 책 등록일 및 지원 형식 다운로드.
- **유사한 책.** 같은 작가, 공통 장르·태그를 기준으로 다른 시리즈 추천.
- **메타정보.** 읽기 전용 정보와 관리자용 시리즈 편집·표지 업로드.

키보드 좌우 방향키와 Home/End로 탭을 이동할 수 있습니다. 모바일에서는 파일 표 안에서 가로 스크롤하며 모든 열을 확인할 수 있습니다. 표지가 없는 책은 빈 이미지 대신 안내를 표시합니다.

## 오디오북·비디오북

트랙/에피소드 목록, 전체 및 개별 재생 진행률, 재생 시간, 파일 경로·크기, 즐겨찾기와 기존 플레이어를 지원합니다. 이어 재생은 현재 트랙/에피소드의 저장된 초 위치를 전달하고, 개별 표지 클릭은 해당 항목을 처음부터 재생합니다. Colorscape와 배너도 동일하게 사용할 수 있습니다.

오디오북 추천은 같은 작가, 비디오 추천은 공통 장르를 기준으로 접근 가능한 서재 안에서 조회합니다. 파일 크기는 코어 상세 데이터이며 수정일이 제공되지 않으면 `—`로 표시합니다. 미디어 파일 다운로드는 제공하지 않습니다.

오디오북 관리자 편집은 작가·WEB ID·출판사·소개·표지만 지원합니다. 코어 저장 범위인 동일 제목 또는 폴더명의 오디오북 수와 서재 수를 표시합니다. 비디오북 메타정보는 코어의 상세 저장 API에 비디오 분기가 없어 **읽기 전용**입니다. 아래 일반·성인 도서용 편집·잠금 설명과는 구분됩니다.

## 상세 배경과 필터

장르는 차분한 파란색, 태그는 초록색으로 구분합니다. 클릭하면 코어의 공식 필터 화면으로 이동하며 기존 서재 범위 설정을 따릅니다. 편집 중 이동에는 미저장 확인이 적용됩니다.

상단의 **배너**와 **Colorscape**는 각각 켜고 끌 수 있으며 기본값은 꺼짐입니다. 선택은 현재 브라우저에 저장됩니다. 배너는 메타정보의 배너 이미지를 우선 사용하고 없으면 표지를 상단 전체 폭에 확대합니다. 왼쪽은 그라데이션과 약한 블러로 가독성을 높이고 오른쪽은 블러 없이 표시합니다. Colorscape는 표지의 주요 색상을 브라우저 안에서 추출하여 상세 전체 높이의 그라데이션과 카드의 은은한 색조에 사용합니다. 별도 이미지 업로드나 외부 분석 서비스는 없습니다.

표지가 없거나 외부 이미지의 CORS 정책으로 색상을 읽을 수 없으면 기본 배경을 유지합니다. 저장소가 차단된 환경에서는 현재 페이지에서만 선택이 유지됩니다. [Kavita Colorscape](https://wiki.kavitareader.com/guides/themes/)의 동작을 참고했으며 동일한 색상 추출 알고리즘은 아닙니다.

## 설치

패키지의 `detail_studio` 폴더를 BookOasis의 `plugins/metadata/` 아래에 둡니다.

```text
plugins/metadata/detail_studio/
  __init__.py
  detail_studio.py
  VERSION
  detail/
    index.html
    style.css
    script.js
```

플러그인을 다시 로드한 뒤 **설정 → 플러그인 관리 → 도서 상세페이지 렌더러**에서 사용할 일반/성인/오디오북/비디오 세션 각각에 Detail Studio를 선택합니다. 해당 메뉴가 없다면 `detail_view` 계약이 포함된 코어가 필요합니다. 되돌리려면 렌더러를 코어 기본값으로 변경합니다.

`preview/`, `tests/`, 개발 문서는 서버에 복사하지 않아도 됩니다. 설치 저장소에는 런타임·README·LICENSE만 포함합니다. 현재 자동 업데이트 주소는 선언하지 않았습니다.

## 데이터와 편집 범위

초기 화면은 코어의 `{meta, books, seriesName, libraryId}`를 그대로 사용합니다. 추가 파일 정보와 추천은 공용 `/api/media/dashboard/widgets/detail_studio/data` 경로를 재사용하며 별도 데스크 위젯을 생성하지 않습니다.

플러그인 데이터 조회는 로그인, 기본 비밀번호 상태, 성인 접근 권한, 서재 접근 권한을 서버에서 확인합니다. DB Gateway를 통해서만 조회하며 DB를 직접 수정하지 않습니다. 추천 캐시는 접근 가능한 서재 목록과 기준 메타정보에 따라 분리됩니다.

**일반·성인 도서 메타정보 저장은 코어의 `POST /api/media/detail/edit`를 사용합니다.** 관리자 전용이며, 현재 코어는 같은 시리즈명의 모든 행을 수정합니다. 다른 서재의 동명 시리즈와 삭제 표시된 DB 행도 범위에 들어갑니다. 저장 전에 적용 권수와 서재 수를 표시합니다. 편집 실패 시 입력을 유지하고, 저장 후 갱신 실패는 저장 실패와 구분합니다.

수정 가능한 항목은 표시 제목(별칭), 작가, 출판사, ISBN, 도서 등급(books_lv), 장르, 태그, 링크, 소개, 표지입니다. 원본 시리즈명 변경, 파일 이름 변경, 파일 내부 메타데이터 쓰기, 필드별 잠금, 독서 세션 분석은 포함하지 않습니다. 저장한 메타정보는 코어 동작에 따라 잠깁니다.

추천은 최대 400권 후보를 정확한 토큰 교집합으로 평가해 시리즈별 중복을 제거하며, 결과를 120초 캐시합니다. 대형 서재에서는 후보 제한 때문에 일부 도서가 빠질 수 있습니다. 추천을 새로 불러와도 캐시 만료 전에는 같은 결과가 나올 수 있습니다. 크기와 수정일은 스캔된 DB 값으로, 실시간 파일 시스템 검사는 하지 않습니다.

코어의 상단 메뉴와 별도 상세 사이드바는 유지됩니다. 프런트는 `/static/js/state.js`, `window.openReader`, `window.openAudioPlayer`, `window.openVideoPlayer`, `window.openBookDetail`에 연결되므로 코어 업데이트 후 이 연결을 확인해야 합니다.

## 검증

로컬 개발 환경에서 SQLite 쿼리·권한 테스트와 브라우저 UI 검사를 수행했습니다. 테스트·미리보기·개발 기록은 설치 저장소에 포함하지 않습니다. NAS·실제 BookOasis 프로세스·MariaDB 통합 검증은 별도입니다.

## 변경 이력

### 0.5.0

- 설정 탭에 시리즈 둘러보기·표지 보기·목록 보기의 표지 크기 조절, 미리보기와 브라우저 저장을 추가했습니다.
- 콘텐츠 등급 배지를 코어 표시 설정과 실질 등급에 맞췄으며, 메타정보 편집에서 books_lv를 선택할 수 있습니다.
- 코어의 그림 작가·팀·장소·등장인물·연재 상태를 표시합니다. 수정 API가 지원하지 않는 필드는 읽기 전용이며 XML 직접 선택 기능은 제공하지 않습니다.
- 일반도서는 공식 rating_widget 조회·저장 API를 사용합니다. 제공자가 없으면 코어 점수의 정적 별표를 유지하며, 별점은 등급·연재 상태 배지 오른쪽에 표시합니다.
- 파일 버튼 옆에 첫 유효 관련 링크의 사이트 바로가기를 추가했습니다. 알려진 사이트는 이름을, 그 외에는 도메인을 표시합니다.
- 버튼 크기와 헤더 간격·글자 대비를 조정하고, 가로 스크롤을 코어처럼 얇고 둥글게 표시합니다.
- 책 소개가 상세 정보 카드 높이를 넘으면 더 보기/접기를 제공합니다. 세로 배치에서는 7줄 기준이며 나의 독서 카드 높이도 줄였습니다.
- 안내는 화면 하단 토스트로 표시하고 일반 안내는 4초, 오류는 7초 후 숨깁니다.

### 0.4.4

- 외부 리더용 OPDS 다운로드 연결을 제거했습니다. 공식 API가 지원하는 EPUB/PDF/TXT만, 다운로드 권한이 있을 때 표시합니다. ZIP/CBZ 다운로드 버튼은 제공하지 않습니다.
- books_lv가 있으면 장르 앞에 방패 아이콘과 등급을 표시합니다. 코어의 실질 등급 값을 우선 사용합니다.
- 파일·추천 조회에 코어 콘텐츠 등급 판정을 적용하고 추천 캐시를 사용자 등급 및 성인 키워드 설정별로 분리했습니다.
- 메타정보 저장 시 기존 books_lv를 함께 전송합니다.
- PC에서 펼친 전체 경로가 표 전체 너비를 사용하며, 전체 너비보다 긴 경우에만 가로 스크롤합니다. 모바일 줄바꿈은 유지합니다.
- 수정일을 책 등록일과 같은 YYYY-MM-DD 형식으로 통일했습니다.
- LIBRARY 경로 구분자 양옆 간격을 넓혔습니다.
- 최신 api.auth와 ContentRatingService가 필요합니다. 구버전 코어는 추가 정보 조회를 지원하지 않습니다.

### 0.4.3

- 일반·성인 도서의 개요/시리즈 권별 표지 우클릭을 코어 도서 메뉴에 연결했습니다.
- 왼쪽 대표 표지는 첫 권을 대상으로 메뉴를 엽니다. 권별 메뉴는 해당 도서 ID와 시리즈 정보를 전달합니다.
- 편집 중이거나 저장 중에는 메뉴를 차단해 입력을 보호합니다.
- 메뉴에서 표지·메타정보·읽기 상태를 변경한 뒤에는 상세페이지를 다시 열어 최신 정보를 확인해야 합니다. 코어의 기본 화면 전용 갱신은 재구현하지 않습니다.
- 오디오북·영상에는 이번 우클릭 메뉴를 연결하지 않습니다. 메뉴 항목과 추가 플러그인 항목은 코어에서 결정합니다.

### 0.4.2

- 배너 왼쪽 그라데이션을 강화하고 오른쪽 블러를 제거했습니다.
- `LIBRARY > 도서종류 > 카테고리` 경로와 유형·카테고리 홈 이동을 추가했습니다.
- 즐겨찾기·컬렉션 버튼을 나란히 배치하고 파일 버튼을 아래로 옮겼습니다. 컬렉션은 코어 선택 창을 사용합니다.
- 작가·출판사·권수 아이콘을 추가했습니다. 작가는 검색으로 이동하며 출판사는 코어 필터 미지원 안내만 표시합니다.
- 안내 메시지를 MY READING 아래로 이동했습니다.
- 개요·시리즈 커버에 어두운 오버레이, 중앙 읽기/재생 아이콘과 강조 테두리를 추가했습니다. 키보드 포커스도 지원합니다.

### 0.4.1

Flask가 영문 RFC 형식으로 반환한 책 등록일이 잘리던 문제를 수정했습니다. SQL/ISO 및 RFC 날짜를 YYYY-MM-DD로 표시합니다.

### 0.4.0

시리즈 목록 표지·텍스트 확대, 보기 전환 툴팁, 선택 즐겨찾기 노란 별, 파일 표 글자 확대와 파일별 책 등록일을 추가했습니다. ZIP/CBZ는 코어 OPDS 다운로드에 연결합니다. ZIP은 코어에서 CBZ로 제공하며 성인 서재 OPDS는 관리자만 사용 가능합니다. EPUB/PDF/TXT는 기존 다운로드 API를 사용합니다. 개별 등록일이 제공되지 않으면 —로 표시하며 시리즈 날짜로 대체하지 않습니다.

### 0.3.2

탭 뒤까지 배경이 이어지도록 상단 바를 투명하게 하고 옵션 박스 테두리를 제거했습니다. 밝은 글자와 선택 탭 강조는 유지합니다.

### 0.3.1

탭 바와 배경 옵션의 테마별 대비를 높이고 선택 배경·밑줄·테두리·키보드 포커스를 강화했습니다.

### 0.3.0

오디오북·비디오북 세션과 부모 ID 기준 권한·추천 조회를 추가했습니다. 코어 플레이어, 초 단위 이어 재생, 트랙/에피소드 진행률과 파일 정보, 오디오북의 지원 필드 편집을 연결했습니다.

### 0.2.1

Colorscape를 상세 전체 높이와 카드 색조에 적용하고, 배너를 상단 전체 폭으로 확장하여 블러를 줄였습니다.

### 0.2.0

장르·태그 색상 구분과 공식 필터 이동, 독립적인 배너·Colorscape 토글, 브라우저 설정 저장 및 회귀 검사를 추가했습니다.

### 0.1.0

첫 로컬 구현. 5개 상세 탭, 권한별 파일/추천 조회, 기존 리더·메타정보 편집 연결, 반응형 테마, 미리보기 및 검증 추가.

아이콘은 BookOasis에 포함된 Font Awesome Free를 사용합니다. BookOrbit 코드나 자산은 포함하지 않았습니다.

## 표지 설정·평점·코어 메타정보

설정 탭에서 세 가지 표지 너비를 조절하고 미리보기로 확인합니다. 크기는 브라우저에 저장됩니다.

평점은 일반도서에서 활성 rating_widget 제공자가 있을 때 공식 조회/제출 API에 연결합니다. 제공자가 없거나 조회에 실패하거나 일반 이외 세션이면 코어 score의 정적 별표를 표시합니다. 별점 저장에는 코어에서 평점 플러그인을 활성화해야 합니다.

등급과 연재상태는 같은 줄에, 장르·태그는 그 아래 표시합니다. 그림 작가·팀·장소·등장인물은 코어 메타정보에서 읽어 표시합니다. 현재 상세 수정 API에 없는 필드는 읽기 전용입니다. XML 직접 선택 기능은 제거했습니다. 기존 도서는 강제 재스캔해야 코어가 새 ComicInfo 필드를 채울 수 있습니다.

확인 기준은 코어 main 9ba7c93입니다. MCP Tier A/B 및 대시보드 Shadow DOM 계약은 상세페이지 플러그인에 직접 적용하지 않습니다. 플러그인은 DOM textContent와 URL 검증을 사용하며 MCP 권한을 통해 상세 수정 제한을 우회하지 않습니다.
