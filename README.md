# Detail Studio

BookOasis의 도서 상세페이지를 개요·시리즈·파일·메타정보·설정 탭으로 제공하는 플러그인입니다.

| 항목 | 내용 |
| --- | --- |
| 버전 | 1.0.0 |
| 지원 세션 | 일반·성인 도서, 오디오북, 비디오 |
| 확인한 코어 | BookOasis main `b36dd3c` |
| 필수 계약 | `detail_view`, DB Gateway, 최신 추가 메타정보·카테고리 속성 스키마 |
| 외부 의존성 | 없음. 코어의 Flask·Font Awesome·리더·플레이어를 사용합니다. |

## 주요 기능

- **개요** — 대표 표지, 이어 읽기, 소개 더 보기, 독서 현황, 전체 권 가로 스크롤과 그 아래 유사한 책 추천.
- **시리즈** — 표지/목록 보기, 제목 검색과 읽기 상태 필터. 우클릭과 모바일 길게 누르기로 코어 도서 메뉴 열기.
- **듣기** — 일반·성인 서재 TXT/EPUB의 첫 권 및 권별 듣기. 코어 `canListen/openListen`이 있는 경우 표시하며 재생 위치 동기화는 코어가 처리합니다.
- **컬렉션** — 버튼 아래 오버레이에서 테마색과 포함 상태를 확인하고 추가·제거. 새 컬렉션 생성은 코어 창을 사용합니다.
- **평점** — 일반 서재의 활성 `rating_widget` 제공자에 연결하며 0.5점 단위 입력을 지원합니다. 제공자가 없으면 기존 정적 별표를 표시합니다.
- **파일** — 경로 펼치기/복사, 형식·스캔 용량·수정일·등록일과 권한에 따른 지원 형식 다운로드.
- **메타정보** — 관리자 편집, 표지 업로드, 카테고리 속성과 추가 메타정보. 관련 사이트는 상세정보의 아이콘으로 이동합니다.
- **홈 데일리 픽** — 선택한 일반·성인 보관함에서 시리즈별로 오늘의 작품을 최대 5개 선정하는 가로 배너. 표지·소개·읽기·상세보기와 작품 전환을 제공합니다.
- **홈 좋은 글귀** — 데일리 픽 대신 선택할 수 있는 한·영 글귀 위젯. 다른 글귀·언어 전환·배경 변경·출처 보기와 본문·저자의 개별 글꼴·크기 선택을 지원합니다.

데일리 픽은 6초 간격으로 가로 전환되며 이전·일시중지/재생·다음 버튼을 제공합니다. 마우스를 올리거나 키보드로 접근하면 전환을 멈추며, 모션 축소 설정에서는 정지 상태로 시작합니다. 코어 기본 폰트를 사용하고 장르·태그 칩과 보관함 링크로 필터·목록에 이동할 수 있습니다.

추가·제거 등 결과는 하단 알림으로 표시합니다. 일시적인 조회 오류는 한 번 재시도하며 쓰기 요청은 자동 재시도하지 않습니다. 인증 실패와 비정상 서버 응답은 구분해 안내합니다.

## 화면 설정

정보 위치를 **제목 아래 / 대표 커버 아래**로 선택합니다. 대표 커버 아래 상세정보는 테두리 없이 버튼과 같은 폭으로 표시합니다.

배너, Colorscape, 커버 블러를 스위치로 선택할 수 있습니다. 커버 블러는 다른 배경 효과보다 우선하며 책 소개·상세정보 등의 카드 배경을 투명하게 만듭니다. 끄면 기존 배경 설정으로 돌아갑니다. 표지가 없거나 이미지 접근이 제한되면 기본 배경을 사용합니다.

시리즈 둘러보기·표지 보기·목록 보기의 표지 크기는 슬라이더 또는 숫자로 조절합니다. 설정은 현재 브라우저에 저장됩니다. **상단 메뉴 자동 숨김**은 기본 해제이며, 데스크톱에서 5초간 클릭이 없으면 숨기고 상단 마우스 오버나 키보드 접근으로 복원됩니다. 모바일에는 적용하지 않습니다.

모바일은 제목 → 큰 표지·버튼·진행률 → 소개 → 독서 현황 → 시리즈 → 유사한 책 → 상세정보 순서입니다. 상단은 왼쪽 뒤로가기 화살표와 우측 탭을 한 줄에 표시하고, 좁은 화면에서는 탭 영역을 가로 스크롤합니다. 탭은 키보드 방향키와 Home/End로 이동할 수 있습니다.

## 설치

아래 파일을 `plugins/metadata/detail_studio/`에 설치합니다.

```text
__init__.py
detail_studio.py
quotes.py
quote_http.py
quote_media.py
quote_store.py
quote_translation.py
VERSION
dashboard.html
dashboard.css
dashboard.js
settings.html
settings.css
settings.js
detail/
  index.html
  script.js
  style.css
```

플러그인을 다시 로드한 뒤 **설정 → 플러그인 관리 → 도서 상세페이지 렌더러**에서 사용할 세션마다 Detail Studio를 선택합니다. 코어 기본 화면으로 돌아가려면 렌더러 선택을 변경합니다. 자동 업데이트 주소는 선언하지 않았습니다.

**플러그인 관리 → Detail Studio → 홈 위젯 선택**에서 데일리 픽 또는 좋은 글귀 하나를 고릅니다. 기본값은 데일리 픽입니다. 데일리 픽 상세 설정에서 보관함을 선택하고 설정을 저장합니다. 일반·성인 도서 세션별로 설정합니다. **내 설정 → 홈 화면 플러그인 배치 모드**를 켠 뒤 홈의 **위젯 추가 → 데일리 픽 · 좋은 글귀**를 선택합니다. 슬롯에는 선택한 위젯만 표시됩니다. 제목줄 없는 배너 표시는 BookOasis 2.9.4 이상을 사용합니다.

보관함 선택은 가용 화면 폭에 따라 열 수를 늘려 표시합니다. 글꼴 설정은 기본 언어/배경, 한국어 글꼴/크기, 영어 글꼴/크기, 저자 글꼴/크기, 사진 API 키 순으로 배치합니다. 오른쪽 미리보기에서 선택한 글꼴과 크기를 바로 확인하며 좁은 화면에서는 미리보기가 아래로 내려갑니다. 미리보기는 설정 크기를 표시하며 홈에서는 카드 공간에 맞춰 축소될 수 있습니다.

데일리 픽 배경은 선택된 대표 도서에 저장된 배너를 우선 사용하며, 배너가 없거나 로딩에 실패하면 표지를 확대해 블러·그라데이션으로 표시합니다. 이미지가 모두 없으면 기본 그라데이션을 사용합니다. 데일리 픽은 본문 이미지 추출이나 외부 배경 수집을 하지 않습니다. 작품 목록은 서버 날짜 기준으로 매일 바뀌며, 후보 ID를 10분간 캐시하고 도서·접근 권한·연령등급은 요청마다 다시 확인합니다.

## 좋은 글귀 카드 설정

별도 플러그인을 설치하지 않습니다. Detail Studio의 홈 슬롯 하나에 데일리 픽 또는 좋은 글귀 중 선택한 위젯만 표시합니다. **홈 위젯 선택**을 좋은 글귀로 바꾸고 설정을 저장하면 적용됩니다. 두 상세 설정은 선택과 관계없이 미리 편집할 수 있습니다. 기존 설정에서 데일리 픽을 끄고 좋은 글귀만 켰던 경우에는 좋은 글귀 선택을 유지하며, 새로 저장한 선택이 우선합니다. 홈 슬롯의 코어 제거 버튼은 선택된 위젯을 홈에서 제거합니다.

- **즉시 사용** — 좋은 글귀를 선택하면 별도 키나 임포트 없이 Korean Advice API의 한국어 문구를 사용합니다. 홈 첫 화면은 같은 설정에서 마지막으로 받은 문구 또는 자체 문구와 그라데이션을 즉시 표시한 뒤 글귀와 배경을 각각 불러옵니다. 배경은 아래 변경 주기 안에서는 기존 선택을 재사용합니다. 외부 응답이 늦거나 실패해도 위젯 전체가 숨은 채 기다리지 않습니다. 외부 문구나 이미지는 설치 파일에 포함하지 않습니다.
- **글꼴과 크기** — 한국어·영어·저자의 글꼴을 코어 설치 목록에서 각각 선택하며 기본값은 코어 글꼴입니다. 삭제되거나 로딩에 실패한 글꼴은 해당 영역만 코어 글꼴로 대체합니다. 한·영 본문은 각각 **16~96px**, 기본32px로 설정합니다. 영어 설정이 없는 이전 구성은 기존 본문 값을 이어받으며, 영어 글꼴을 코어 기본값으로 명시하면 한국어와 독립적으로 적용됩니다. 모바일은80% 배율이며 실제 크기는 아래 고정 높이에 맞춰 줄어들 수 있습니다. 저자는 실제 표시 본문보다 작게 조정합니다.
- **높이와 긴 문구** — 카드 높이는 데스크톱360px·모바일380px로 고정합니다. 가로 공간을 넓게 쓰고 줄 간격을 줄인 뒤, 설정한 한·영 크기의 비율을 유지하면서 문구와 저자가 들어가도록 축소합니다. 최소12px에서도 아주 긴 내용은 내부 영역에서 스크롤해 전체를 읽을 수 있습니다. 언어·글꼴 로딩·화면 폭이 바뀌면 다시 맞춥니다.
- **표시와 도구** — 제목에는 은은한 배경을, 저자에는 배경 없는 아이보리 글자와 양쪽 하이픈을 적용합니다. Korean Advice의 소개가 있으면 `- 저자, 소개 -`로 표시합니다. DeepL 자동번역 표시는 오른쪽 아래 새로고침 아이콘 왼쪽에서 코어 글꼴로 표시합니다. 다른 글귀·배경 변경은 투명한 아이콘 버튼으로 사용하며, 언어 버튼은 `En` → `한` → `En.한` 순서로 전환합니다. 제공처·원전·사진 출처는 정보 아이콘의 반투명 패널에서 확인하며 긴 경우만 스크롤합니다. 마우스·키보드·터치로 열고 Escape 키로 닫습니다.
- **한국어 글귀** — 기본 공급원은 [Korean Advice API](https://github.com/gwongibeom/korean-advice-open-api)이며 한국어 원문과 저자를 그대로 표시하고 번역하지 않습니다. 출처창에서 저장소와 이용 조건을 확인할 수 있습니다. [제공자 라이선스](https://github.com/gwongibeom/korean-advice-open-api/blob/main/LICENSE)는 비상업적 무료 사용·출처 표기를 요구하며 상업적 이용은 별도 협의가 필요합니다. API가 개별 문구의 원전이나 권리를 보증하는 것은 아닙니다. Quotable 임포트·검수 기능은 제거했습니다.
- **공급원 비중** — Korean Advice·ZenQuotes·PositiveQuotation의 기본 가중치는 **60:35:5**입니다. 기존 영문 두 소스의 가중치는 유지하며 이전 로컬 가중치는 한국어 소스에 이어집니다. ZenQuotes와 PositiveQuotation은 사용 여부와 이용 범위 확인을 모두 켜야 작동합니다. 꺼지거나 장애가 난 공급원의 비중은 나머지에 재분배합니다. ZenQuotes는 최대 50개를 1시간 메모리 캐시로 사용하며 PositiveQuotation은 공식 30개 속담 API만 호출합니다.
- **DeepL 사전 번역** — 번역 대상은 **ZenQuotes·PositiveQuotation의 영문만**입니다. 두 소스의 사용 여부·이용 범위를 확인하고 DeepL API 키와 설정을 저장한 뒤 **대상 확인**을 누릅니다. 서버가 활성화된 영문 소스의 문구를 가져와 전용 SQLite에 저장하고, 미번역 건수·문자 수와 실제 API 사용량·잔여 한도를 표시합니다. 개별 임포트나 게시 검수는 필요하지 않습니다. 최대 10개씩 번역하며 한국어·번역 제공처·일시를 SQLite에 저장합니다. 중지는 진행 중 묶음 저장 후 적용되고 다시 실행하면 남은 항목부터 처리합니다. 기존 번역과 작업 중 변경된 문구는 덮어쓰지 않으며 한도·인증·속도 제한·통신 오류 시 저장한 묶음을 보존하고 중단합니다.
- **번역 표시와 이용량** — 홈은 조회한 영문과 같은 원문의 저장된 한국어를 함께 표시하며 번역 API를 호출하지 않습니다. API에서 새로 만난 영문은 다음 일괄 번역 대상에 추가되고, 아직 번역되지 않은 문구는 영문으로 표시됩니다. 한국어 소스는 언어 설정과 관계없이 한국어로 표시합니다. 자동 번역은 DeepL 출처를 표시하며 키는 서버의 저장된 설정에서만 읽고 번역 요청의 브라우저 payload와 공개 카드에는 포함하지 않습니다. 계정의 실제 문자 한도를 조회해 사용합니다. [API 안내](https://www.deepl.com/en/developers) · [요금제](https://support.deepl.com/hc/en-us/articles/360021200939-DeepL-API-plans) · [이용 조건](https://www.deepl.com/en/pro-license).
- **배경과 The Met** — 기본값은 그라데이션입니다. The Met를 선택하면 공식 Collection API에서 `isPublicDomain === true`이고 `primaryImage`가 있는 작품만 배경으로 사용합니다. API 키와 수동 사진 검수는 필요하지 않으며 작품명·작가·소장 정보·작품 원본·CC0 링크를 출처 보기에 표시합니다. [이미지 이용 안내](https://www.metmuseum.org/ko/policies/image-resources)와 [공식 API 문서](https://metmuseum.github.io/)에서 제공 범위를 확인할 수 있습니다. 기존 Openverse 선택은 그라데이션으로 전환됩니다.
- **Unsplash 무료 사진** — 개발자 Access Key와 이용 조건 확인이 필요합니다. 공식 CDN URL의 `ixid` 등 기존 값을 보존하며 최대 폭 2200px·품질80·자동 형식으로 받아 대용량 원본 전송을 줄입니다. `raw`가 없으면 `full`·`regular` 순으로 사용합니다. Unsplash와 Met 배경에는 흐림·색상 보정·어두운 덮개를 적용하지 않으며 배너 비율에 맞춰 사진을 채웁니다. 새 사진은 미리 로드한 이미지가 준비되면 교체하며 실패 시 기존 배경을 유지합니다. 사진가·Unsplash 링크와 선택 시 다운로드 추적은 유지하고 Unsplash+ 이미지는 사용하지 않습니다.
- **Pexels** — 기존 API 키와 이용 조건 확인이 필요합니다. 사진가·Pexels·라이선스 출처를 표시합니다. 키 발급 가능 여부는 [공식 API 페이지](https://www.pexels.com/api/)에서 확인하세요.
- **배경 변경 주기** — 사진 사이트와 관계없이 기본 **3시간**마다 자동 변경합니다. 좋은 글귀 설정의 **배경 자동 변경 주기**에서 **1~24시간**으로 조절한 뒤 설정을 저장하세요. 새로고침 아이콘은 문구만 바꾸며, 배경 변경 아이콘은 주기와 관계없이 새 사진을 요청하고 주기를 다시 시작합니다. 홈 재진입은 남은 시간을 이어가고 화면이 열려 있으면 만료 시 갱신합니다. URL·출처·남은 시간만 서버 메모리에 유지하며 이미지 파일은 디스크에 저장하지 않습니다. 코어 재시작이나 설정 변경 후에는 새로 선택합니다. 공급원 오류·속도 제한 시 기존 사진을 유지하고 재시도합니다.

사진이나 공급원 API가 실패해도 기본 문구와 그라데이션으로 대체합니다. 최근 글귀 해시 최대 20개만 브라우저 세션에 기록합니다. **영문 두 공급원의 원문·DeepL 번역 캐시는 `plugins/metadata/detail_studio/data/quotes.sqlite3` 전용 파일에 저장하며 코어 DB에 넣지 않습니다.** 최초 사용 시 자동 생성되므로 이 하위 폴더에 쓰기 권한이 필요합니다. 업데이트 시 기존 `data/`를 보존하고 백업에 함께 포함하세요. 이전 Quotable 데이터는 파일에 보존하지만 표시·번역 대상으로 사용하지 않습니다. 생성된 DB는 Git 업로드·배포 파일에서 제외하며 코어가 MariaDB를 사용해도 독립된 SQLite로 동작합니다.

코어 DB에는 기존 관리자 설정 저장 방식으로 표시 옵션·공급원 선택·API 연결 설정만 저장합니다. 공개 카드 응답에는 API 키를 포함하지 않으며, 외부 의존성은 추가하지 않습니다.

저장소에는 실행 파일과 README·LICENSE만 포함합니다. 테스트, 미리보기, 개발 메모는 설치할 필요가 없습니다.

## 편집 범위와 호환성

일반·성인 도서의 기본 메타정보는 코어 편집 API를 사용합니다. **같은 시리즈명의 다른 서재 도서와 삭제 표시된 DB 행도 저장 범위에 포함될 수 있습니다.** 저장 전에 적용 권수와 서재 수를 표시합니다.

그림 작가·팀·장소·등장인물·연재 상태는 관리자 검증을 거친 플러그인 액션으로 코어 DB에 저장합니다. 연재 시작일·종료일·출간일·회차 수는 **Detail Studio 전용 설정**이며 코어 스캐너에 적용되지 않습니다. 기본/추가 정보의 일부 저장 실패는 구분해 안내합니다. XML 직접 선택과 자동 메타데이터 수집은 제공하지 않습니다.

BookOasis 2.8.4 이상의 문제 카드 기능이 있으면 플러그인이 처리하는 추가 메타정보 저장 실패를 관리자 알림센터에 시리즈별로 기록합니다. 같은 시리즈를 다시 저장해 성공하면 해결 처리합니다. 권한·입력 오류는 문제 카드로 기록하지 않으며, 구버전 코어에서는 기존 화면 알림을 사용합니다.

오디오북은 코어 플레이어와 이어 재생, 지원 메타정보 편집을 연결합니다. 비디오는 메타정보 읽기 전용입니다. 오디오북·비디오에는 도서용 TTS와 커뮤니티 별점을 적용하지 않습니다.

컬렉션 제거는 현재 시리즈 항목과 해당 시리즈의 개별 도서 항목 또는 현재 미디어 항목에 적용합니다. 원본 도서 파일은 삭제하지 않습니다. 도서 메뉴에서 변경한 표지·메타정보·읽기 상태는 상세페이지를 다시 열어 확인합니다.

추천은 접근 가능한 서재의 최대 400권 후보에서 시리즈별로 추려 120초 캐시합니다. 파일 정보는 마지막 스캔 값이며 실시간 파일 검사는 하지 않습니다. 로그인·관리자·성인·서재 접근 권한은 서버에서 검사합니다.

로컬 SQLite 테스트와 브라우저 검증, MariaDB 정적 호환 검사를 수행합니다. 실제 NAS·MariaDB·iPhone Safari 및 음성 합성 통합 동작은 별도 확인이 필요합니다.
