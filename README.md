# Detail Studio

BookOasis의 도서 상세페이지를 개요·시리즈·파일·메타정보·설정 탭으로 제공하는 플러그인입니다.

| 항목 | 내용 |
| --- | --- |
| 버전 | 0.9.0 |
| 지원 세션 | 일반·성인 도서, 오디오북, 비디오 |
| 확인한 코어 | BookOasis main `5f174f4` |
| 필수 계약 | `detail_view`, DB Gateway, 최신 추가 메타정보·카테고리 속성 스키마 |
| 외부 의존성 | 없음. 코어의 Flask·Font Awesome·리더·플레이어를 사용합니다. |

## 주요 기능

- **개요** — 대표 표지, 이어 읽기, 소개 더 보기, 독서 현황, 전체 권 가로 스크롤과 그 아래 유사한 책 추천.
- **시리즈** — 표지/목록 보기, 제목 검색과 읽기 상태 필터. 우클릭과 모바일 길게 누르기로 코어 도서 메뉴 열기.
- **듣기** — 일반·성인 서재 TXT/EPUB의 첫 권 및 권별 듣기. 코어 `canListen/openListen`이 있는 경우 표시하며 재생 위치 동기화는 코어가 처리합니다.
- **컬렉션** — 버튼 아래 오버레이에서 테마색과 포함 상태를 확인하고 추가·제거. 새 컬렉션 생성은 코어 창을 사용합니다.
- **평점** — 일반 서재의 활성 `rating_widget` 제공자에 연결하며 0.5점 단위 입력을 지원합니다. 제공자가 없으면 기존 정적 별표를 표시합니다.
- **파일** — 경로 펼치기/복사, 형식·스캔 용량·수정일·등록일과 권한에 따른 지원 형식 다운로드.
- **메타정보** — 관리자 편집, 표지 업로드, 카테고리 속성과 추가 메타정보. 관련 사이트는 상세정보의 아이콘으로 이동합니다.

추가·제거 등 결과는 하단 알림으로 표시합니다. 일시적인 조회 오류는 한 번 재시도하며 쓰기 요청은 자동 재시도하지 않습니다. 인증 실패와 비정상 서버 응답은 구분해 안내합니다.

## 화면 설정

정보 위치를 **제목 아래 / 대표 커버 아래**로 선택합니다. 대표 커버 아래 상세정보는 테두리 없이 버튼과 같은 폭으로 표시합니다.

배너, Colorscape, 커버 블러를 스위치로 선택할 수 있습니다. 커버 블러는 다른 배경 효과보다 우선하며 책 소개·상세정보 등의 카드 배경을 투명하게 만듭니다. 끄면 기존 배경 설정으로 돌아갑니다. 표지가 없거나 이미지 접근이 제한되면 기본 배경을 사용합니다.

시리즈 둘러보기·표지 보기·목록 보기의 표지 크기는 슬라이더 또는 숫자로 조절합니다. 설정은 현재 브라우저에 저장됩니다. **상단 메뉴 자동 숨김**은 기본 해제이며, 데스크톱에서 5초간 클릭이 없으면 숨기고 상단 마우스 오버나 키보드 접근으로 복원됩니다. 모바일에는 적용하지 않습니다.

모바일은 제목 → 큰 표지·버튼·진행률 → 소개 → 독서 현황 → 시리즈 → 유사한 책 → 상세정보 순서입니다. 탭은 키보드 방향키와 Home/End로 이동할 수 있습니다.

## 설치

아래 파일을 `plugins/metadata/detail_studio/`에 설치합니다.

```text
__init__.py
detail_studio.py
VERSION
detail/
  index.html
  script.js
  style.css
```

플러그인을 다시 로드한 뒤 **설정 → 플러그인 관리 → 도서 상세페이지 렌더러**에서 사용할 세션마다 Detail Studio를 선택합니다. 코어 기본 화면으로 돌아가려면 렌더러 선택을 변경합니다. 자동 업데이트 주소는 선언하지 않았습니다.

저장소에는 실행 파일과 README·LICENSE만 포함합니다. 테스트, 미리보기, 개발 메모는 설치할 필요가 없습니다.

## 편집 범위와 호환성

일반·성인 도서의 기본 메타정보는 코어 편집 API를 사용합니다. **같은 시리즈명의 다른 서재 도서와 삭제 표시된 DB 행도 저장 범위에 포함될 수 있습니다.** 저장 전에 적용 권수와 서재 수를 표시합니다.

그림 작가·팀·장소·등장인물·연재 상태는 관리자 검증을 거친 플러그인 액션으로 코어 DB에 저장합니다. 연재 시작일·종료일·출간일·회차 수는 **Detail Studio 전용 설정**이며 코어 스캐너에 적용되지 않습니다. 기본/추가 정보의 일부 저장 실패는 구분해 안내합니다. XML 직접 선택과 자동 메타데이터 수집은 제공하지 않습니다.

오디오북은 코어 플레이어와 이어 재생, 지원 메타정보 편집을 연결합니다. 비디오는 메타정보 읽기 전용입니다. 오디오북·비디오에는 도서용 TTS와 커뮤니티 별점을 적용하지 않습니다.

컬렉션 제거는 현재 시리즈 항목과 해당 시리즈의 개별 도서 항목 또는 현재 미디어 항목에 적용합니다. 원본 도서 파일은 삭제하지 않습니다. 도서 메뉴에서 변경한 표지·메타정보·읽기 상태는 상세페이지를 다시 열어 확인합니다.

추천은 접근 가능한 서재의 최대 400권 후보에서 시리즈별로 추려 120초 캐시합니다. 파일 정보는 마지막 스캔 값이며 실시간 파일 검사는 하지 않습니다. 로그인·관리자·성인·서재 접근 권한은 서버에서 검사합니다.

로컬 SQLite 테스트와 브라우저 검증, MariaDB 정적 호환 검사를 수행합니다. 실제 NAS·MariaDB·iPhone Safari 및 음성 합성 통합 동작은 별도 확인이 필요합니다.

## 변경 이력

### 0.9.0

- 공식 TTS·커뮤니티 반점 평점, 확장 메타정보와 카테고리 속성 지원.
- 모바일 세로 배치, 전체 시리즈 가로 스크롤, 개요 내 유사한 책, 길게 누르기 메뉴 개선.
- 컬렉션 포함 상태에 따른 추가·제거와 색상 오버레이, 하단 알림 통일.
- 커버 블러·정보 위치·메뉴 자동 숨김 옵션과 설정 스위치 UI 정리.
- 표지 크기 직접 입력 및 일시 조회 오류 재시도·인증 안내 개선.

### 0.5.0

표지 크기 설정, 코어 등급·연재 상태·메타정보 표시와 공식 별점 연결, 소개 더 보기 및 알림을 추가했습니다.

### 0.4.x 이하

상세 탭, 파일 정보, 오디오북·비디오 지원, 배너·Colorscape 및 읽기·편집 연결을 추가했습니다.

아이콘은 BookOasis에 포함된 Font Awesome Free를 사용합니다. BookOrbit의 탭 구성과 rabbit 플러그인의 배치·배경 방식을 참고했습니다.
